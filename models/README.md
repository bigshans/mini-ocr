# OCR models

The PP-OCRv5 ONNX models are not committed to this repository (about 21 MB).
Download them with:

```bash
./scripts/fetch-models.sh
```

Files:

- `ch_PP-OCRv5_det_mobile.onnx`
- `ch_PP-OCRv5_rec_mobile.onnx`
- `ppocrv5_dict.txt`

Source: RapidOCR / PaddleOCR model conversion, Apache-2.0.
